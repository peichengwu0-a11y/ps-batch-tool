# 商品图批量画板系统 V2

## 当前版本功能

- 主品库、赠品库支持逐个添加图片，也支持直接选择本地文件夹。
- 文件夹模式读取第一层 PNG、JPG、JPEG、WebP，可点击“刷新文件夹”同步变化。
- 导出时只复制各搭配实际使用的素材，Photoshop 不依赖原始文件夹链接。
- 默认使用“主品高度优先＋主品锁定＋赠品动态填空＋多边形硬边界”。
- 主品、赠品区域作为优先位置，整体产品蒙版作为最终边界。
- 网站直接读取 PSD/PSB 文件头尺寸；比例一致时自动换算，比例不同将禁止导出。
- 执行器会比较横排、两两堆叠、单列堆叠和均衡双列等候选方案。
- 产品及投影安全范围的四角和边中点必须处于整体产品多边形内，否则候选直接淘汰。
- 主品按裁切后的真实高度从高到低排列；高宽比不低于 2 的最长主品优先接近撑满主品区域高度。
- 主品排好后锁定尺寸和位置，再从整体区域扣除主品、间距和投影安全范围。
- 赠品按面积从大到小匹配剩余空位；长赠品偏好窄高空位，矮胖赠品偏好宽大空位。
- 两阶段布局无法安全容纳当前组合时，自动回退到普通硬边界二维候选求解器。
- 排版碰撞和边界判断只计算产品本体，不为投影预留距离；投影越过整体区域的部分由总和组蒙版裁切。
- 主品区域仅作为优先位置，绿色整体区域是产品本体的唯一硬边界。
- 全部产品放置后逐件自动膨胀，直到继续放大会碰撞或越界。
- 高宽比不低于 2 的主品先按真实高度排序，并在红色主品多边形中独立锚定。
- 长条主品会读取其左侧、中心、右侧对应的多边形上下边界，尽量同时贴合可用顶部与底部。
- 长条主品锚定后锁定尺寸和位置，其他主品、赠品及最终膨胀不会再改变它。
- 当整体产品蒙版接近正视矩形时，自动切换到正视礼盒布局：主品按重要性分列，小赠品优先上下组合，整组底部对齐并居中放大。
- 正视布局的所有产品本体仍需完全位于整体产品蒙版内；无法容纳时自动回退到多边形硬边界布局。
- 主品组投影预设：正片叠底、41%、140°、距离 14px、扩展 14%、大小 12px。
- 赠品组投影预设：正片叠底、34%、140°、距离 9px、扩展 18%、大小 8px。
- 从任务版本 18 开始，礼盒投影可按搭配分别调整主品与赠品的不透明度、角度、距离、扩展、大小和颜色，也可联动为同一套参数。
- 网页礼盒投影为 Canvas 近似预览；导出任务会把相同数值精确写入 Photoshop 主品组与赠品组的图层样式。
- 每组搭配可独立选择“礼盒投影”或“太阳光投影”；礼盒投影保留原主品/赠品图层样式，太阳光模式在圆形控制器中拖动太阳。
- 网页使用产品真实透明剪影生成红色斜切投影预览；太阳越低投影越长，光源越大投影越柔。
- 多选产品剪影后可统一调整“投影长度修正”20%～180%，默认 100% 直接使用剪影像素高度。
- 从任务版本 17 开始，每件产品分别输出 `_sun.png` 太阳投影和 `_contact.png` 接触阴影。接触阴影由产品底部真实透明轮廓压缩、柔化生成，不再使用硬椭圆。
- 从任务版本 19 开始，太阳光模式新增“接触阴影贴合”。默认 1.6%，相当于在 750px 短边画布上向产品内部上移约 12px；实际位移按画布短边缩放，同时以产品高度 1.5% 为下限、画布短边 2% 为上限，确保不同尺寸画布中的贴合关系稳定。
- Photoshop 将太阳投影与接触阴影放进两个独立子组，可分别调不透明度、混合模式和蒙版；两个图层都与对应产品链接。
- 完整任务包的 `shadows` 文件夹不能删除；投影文件缺失时才回退到旧版兼容算法。选择礼盒投影时完全使用原礼盒投影逻辑。
- 每组搭配提供统一的“排版优先级”列表，可用左右箭头调整主品与赠品的混合优先级。
- 正视模板中第 1 位作为锚点：长条产品尽量贴满区域上下，方形或圆形产品最大约占区域高度 82%，放置后锁定。
- 第 2 位作为核心产品，优先匹配最大的剩余空位并尽可能放大；其余产品依次匹配剩余空位。
- 每个导出素材使用“唯一 ID＋原文件名”，即使素材库中出现同名文件也不会互相覆盖；PS 会严格按任务中的完整路径匹配锚点与核心。
- 核心产品使用最大剩余空间约 99.5% 的适配比例，并强制保证最长边至少为其他赠品的 1.5 倍；其余赠品缩放后贴近空位边缘。
- 全部放置后，在不越出整体蒙版且不碰撞的前提下逐件膨胀，减少空白并提高选区饱满度。
- 独立接触阴影优先读取每件产品的真实透明轮廓，分别模糊、偏移并链接产品；只有无法读取透明通道时才使用底部窄影，避免多件产品连成整条灰黑阴影。
- 结果文档始终以单个模板尺寸初始化，保证 Photoshop 创建的每一个画板都与模板尺寸一致。
- 从任务版本 21 开始，可导入“文字与产品自动搭配测试模板.xlsx”：网站先检查文字、主品、赠品、数量和优先级，素材缺失时不会覆盖当前搭配。
- Excel 素材编号优先通过“素材说明”中的文件名匹配，也支持产品图片文件名直接以 `P001_`、`G001_` 等编号开头。
- PSD 仍不需要预放产品图层；执行器继续自动导入主品、赠品、投影并建立原有产品组。
- 产品素材采用“单次置入＋智能对象缓存复用”：每个唯一文件只置入一次，重复数量和其他画板直接复制缓存图层，避免大型多画板 PSD 反复打开、关闭 PNG 导致 Photoshop 中断。
- 从任务版本 22 开始，执行器会为每个画板复制完整、可编辑的模板图层结构，在复制出的 `可变文字` 组内直接修改原文字层内容。脚本不再重新创建、移动或缩放文字层。
- Logo、Icon、智能对象、图层样式、文字字号、行距、字距和对齐均沿用 PSD 模板；产品组仍由执行器自动创建。
- 第 2 个及之后画板的产品组会临时移至文档原点建立局部区域蒙版，再连同蒙版移回对应画板，避免选区被普通画布边界裁切。
- 每件产品完成排版后会再次检查真实图层边界和父级：脱离产品组时强制归组，越出整体产品区域时自动缩小并回拉；仍无法容纳则直接报告具体素材名。

直接使用 Chrome 或 Edge 打开 `index.html`。

## 正确流程

1. 素材库：选择主品、赠品文件夹，或逐个添加需要自动排列的图片。
2. 模板区域：上传固定背景、Icon、文字已经制作完成的 PSD，并上传同尺寸预览图。
3. 在预览图上绘制主品排列区域、赠品排列区域和整体产品蒙版，可使用矩形或多边形套索。
4. 批量搭配：添加多组搭配，每组选择主品和赠品，可复制或删除组合。
5. 导出完整 Photoshop 任务。
6. 在 Photoshop 2026 中运行任务文件夹内的 `运行本任务.jsx`。
7. 脚本为每组搭配创建一个同尺寸画板，复制完整可编辑模板，在 `可变文字` 组内原位替换文字，并在对应区域内自动排列产品。

## Excel 文字与产品导入

先在素材库读取主品、赠品文件夹，再进入“批量搭配”点击“导入 Excel”。网站会显示导入检查结果；只有全部必填文案和产品素材匹配成功后，才允许替换或追加搭配。

PSD 模板必须包含名为 `可变文字` 的图层组，并在该组内保留以下原生文字图层。Logo、Icon 和赠品版智能对象保持原模板内容：

```text
文字_主标题_黑
文字_强调标题_红
文字_活动文案
文字_产品名称
文字_底部购买明细
文字_底部赠品明细
```

产品图层和产品组都不需要在 PSD 中建立。执行器会创建 `主品加赠品加投影`、`主品`、`赠品` 和 `投影` 组。六个文字层必须位于 `可变文字` 组内且名称完全一致；执行器只替换文字内容，不调整位置和排版属性。模板缺少组或文字层时会明确报告名称。

画板尺寸以 PSD 文档真实尺寸为准。每个画板内的主品和赠品分别采用：

```text
主品加赠品加投影（整体产品蒙版）
├─ 主品（Photoshop 图层样式投影）
├─ 赠品（Photoshop 图层样式投影）
└─ 投影（全部独立接触阴影，并分别链接对应产品）
```

启用太阳光投影时，投影组内包含“太阳投影（可单独调整）”与“接触阴影（可单独调整）”两个子组；任务包必须整体保留，不能只拿出 JSX 单独运行。

生成结果保存在任务文件夹的 `output` 目录。
